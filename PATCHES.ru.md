# Серверные патчи YourOwn.Chat для Mattermost 11.10

Ветка основана на официальном теге Mattermost Team Edition `v11.10.0` и
намеренно содержит только серверные изменения. Кастомный web-клиент версионируется
и выпускается отдельно из `pilprod/yourown-chat-web`.

## Аутентификация и идентификация

- Добавлен универсальный провайдер OpenID Connect с кешированием JWKS,
  проверкой подписанного JWT, привязкой по `sub` и дополнением данных из claims,
  когда ответ `userinfo` неполный.
- Добавлено получение групп и участников через Keycloak Admin API за штатными
  интерфейсами синхронизации групп. Вход пользователей остаётся OIDC;
  LDAP bind-аутентификация не реализуется.
- Для обычных auth-cookie явно задан `SameSite=Lax`; штатный режим
  `SameSite=None; Secure` для embedded-сценариев сохранён.

## Поведение сервера

- Добавлены серверные значения по умолчанию для синхронизации темы с ОС и
  явного поведения click-to-reply у новых пользователей.
- Неизменяемый URL Corresponding Source передаётся в клиентскую конфигурацию и
  метаданные серверной сборки.
- Публичная продуктовая сборка остаётся Team-only: каталога
  `server/enterprise` и enterprise-only wiring команд в ветке нет.
- Публичные feature-метаданные используются только собственными путями OIDC и
  синхронизации групп Keycloak; Mattermost Enterprise код не импортируется.

## Граница релиза

В серверном форке больше нет Dockerfile и webapp-патчей. Сборка образа,
фиксация toolchain, SBOM/provenance, сканирование уязвимостей и продвижение через
Cloud Deploy находятся в `pilprod/yourown-chat-mattermost` и публичном
репозитории платформы. Одна версия продукта `X.Y.Z[-suffix]` использует:

- серверный тег `vX.Y.Z[-suffix]-patched`;
- web-тег `X.Y.Z[-suffix]`;
- тег сборочного репозитория `X.Y.Z[-suffix]`.

Точный SHA сервера вшивается в бинарник и записывается Cloud Build в OCI
provenance.
